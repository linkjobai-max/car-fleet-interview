Car Fleet in Coding Interviews: Sort by Position, Compare Arrival Times

The problem

LeetCode 853: n cars drive toward the same target on a one-lane road. Car i starts at position[i] with speed[i]. A car can never pass the car ahead; when it catches up, they move together as one fleet at the slower speed. Return how many fleets arrive at the target.

The key observation

Simulating time steps is messy and slow. Instead, compute each car's arrival time if it drove alone: (target - position) / speed. A car only joins a fleet ahead of it, never one behind it, so process cars from the one closest to the target backwards.

Walking backwards, keep the arrival time of the current lead fleet. If the next car would arrive later than that time, it can never catch up, so it starts a new fleet and becomes the new lead. If it would arrive earlier or at the same time, it catches up and merges, and its own time no longer matters.

Code

def car_fleet(target, position, speed):
    cars = sorted(zip(position, speed), reverse=True)
    fleets, lead_time = 0, 0.0
    for pos, spd in cars:
        t = (target - pos) / spd
        if t > lead_time:
            fleets += 1
            lead_time = t
    return fleets

Complexity and what to say

Sorting costs O(n log n) and the scan is O(n), with O(n) extra space for the pairs. Many solutions use a stack of times, but you only ever look at its top, so a single variable is enough. Point that out; interviewers like seeing you simplify a stack you do not need.

Edge cases worth naming: a car exactly at the target position (time 0), equal times that merge exactly at the target (they count as one fleet, hence the strict greater-than), and floating point. If precision worries the interviewer, compare (target - p1) * s2 against (target - p2) * s1 with integers.

Follow-ups

Car Fleet II (LeetCode 1776) asks for the time each car collides with the next fleet; it uses a monotonic stack from the right and is a good next problem. The same sort-then-sweep pattern shows up in meeting merges and in skyline-style questions.
